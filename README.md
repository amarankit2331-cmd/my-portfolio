# Amar Kant Nayak — Portfolio (AMAR.exe)

Brutalist, terminal-inspired developer portfolio built with Next.js 15,
React 19, Tailwind CSS 4 and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
- `./node_modules/.bin/tsc --noEmit` — type check

## Structure

- `app/` — root layout, home page, global styles
- `components/` — page sections (`Navbar`, `Hero`, `About`, `Skills`,
  `Logs`, `Projects`, `Contact`, `Footer`), the cinematic intro
  (`CinematicIntro`, `IntroHands`, `Disintegration`,
  `DecorativeSymbols`), and reusable pieces (`ui/Card`,
  `ui/motion`, `Magnetic`, `MathField`, `Marquee`, `ProjectCard`,
  `SectionHeading`)
- `public/Amar_Kant_Nayak_CV.pdf` — downloadable CV
